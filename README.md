# Tic-tac-toe game with AI
## Description

This project is a python based Tic-Tac-Toe game, where the user is able to play against the computer.

The computer uses the Minimax algorithm to make its moves and play optimally.

This was my personal task for my internship to learn more about Python programming and to gain experience with the Python language.
The features of the game are as follows:
- A 3×3 interactive Tic-Tac-Toe board
- Playing against the computer opponent
- The computer uses the Minimax algorithm as its AI
- Winning/Losing/Drawing conditions
- Visualizing the board after every move
- The ability to rematch after a game is over
The technologies used to develop the project are:
- Python 3
- Minimax Algorithm
The following steps must be undertaken in order to run the project:
1. Install Python 3 in the local machine
2. Clone or download this repository
3. Open the terminal/command prompt inside the project directory
4. Then run this command inside the terminal/command prompt
python tic_tac_toe.py
Once the Python file is run, the game can be played by following the instructions provided on the terminal.
The steps to play the game are as follows:
1. The Python file must be run
2. The user must follow the on-screen instructions
3. The user must enter their move when prompted to do so
4. The computer will make its move on its own turn
5. The game ends when a player wins or when the board gets filled
I learned from this project how Python functions, loops, conditions and lists work, and how they can be used to develop a game.
I also learned about the Minimax algorithm and how it can be used to teach a computer to play as an opponent.
